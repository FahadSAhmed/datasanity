# `datasanity`

Data-quality checks for tabular research and clinical datasets.

## Example

```bash
datasanity check examples/messy_clinical_data.csv
```

## Current version

MVP `0.1.0` with a small Python API, CLI entry point, and tests.

## Next expansion targets

- Broader domain-specific rules.
- Richer HTML reports.
- Configuration files.
- More tests and real-world examples.
- Documentation with biomedical/clinical research examples.
